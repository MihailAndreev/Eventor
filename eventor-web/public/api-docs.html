Eventor REST API

Minimal mobile API for Expo clients. It supports login, listing active events, reading event details, joining, leaving, and reserving extra slots.

Base URL /api
Format JSON requests and JSON responses, except this documentation page.
Authentication Send Authorization: Bearer <token> on protected endpoints.

Authentication

Call POST /api/auth/login with an existing user email and password. Store the returned JWT token in the mobile app and attach it as a bearer token for every events endpoint. 

Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

Web pages use cookies, but this REST API uses bearer tokens so native mobile clients do not need browser session cookies.

Common Responses

Status Meaning Response
200 Request succeeded. Endpoint-specific JSON payload.
400 Invalid input, full event, inactive event, or unsupported action. { "error": "Message" } or { "ok": false, "message": "Message" }
401 Missing or invalid bearer token. { "error": "Missing or invalid bearer token." }
403 The user is not a member of the group that owns the event. { "error": "You are not a member of this event group." }
404 Event id is invalid or the event does not exist. { "error": "Event not found." }
POST /api/auth/login Public

Login by email and password. Returns a JWT bearer token and basic user data.

Request Body

Field Type Required Description
email string Yes User email address.
password string Yes User password.

Example Request

curl -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "alex@example.com",
    "password": "password123"
  }'

Example Response

{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "tokenType": "Bearer",
  "user": {
    "id": 1,
    "email": "alex@example.com",
    "name": "Alex Morgan",
    "role": "user"
  }
}
GET /api/events Bearer token required

Lists active events open for joining. Results include only upcoming and current events that are not canceled, and only events from groups where the logged-in user is a member.

Query Parameters

Name Type Default Description
page integer 1 One-based page number.
pageSize integer 20 Items per page. Maximum returned by the service is 100.

Example Request

curl "http://localhost:3001/api/events?page=1&pageSize=20" \
  -H "Authorization: Bearer <token>"

POST /api/events/{id}/join Bearer token required

Joins an active event if the user is a member of the owning group and capacity allows it. Calling this endpoint when already joined is safe.

Example Request

curl -X POST http://localhost:3001/api/events/42/join \
  -H "Authorization: Bearer <token>"

Example Response

{
  "ok": true,
  "message": "Joined event."
}
POST /api/events/{id}/leave Bearer token required

Leaves an event by marking the user's participation as not going. Any extra reserved slots are cleared. Calling this endpoint when not joined is safe.

Example Request

curl -X POST http://localhost:3001/api/events/42/leave \
  -H "Authorization: Bearer <token>"

Example Response

{
  "ok": true,
  "message": "Left event."
}
POST /api/events/{id}/slots Bearer token required

Sets extra reserved slots for friends or family members. The value represents additional people beyond the logged-in user. The user must already be joined.

Request Body

Field Type Required Description
extraSlots integer Yes Non-negative number of additional slots to reserve.

Example Request

curl -X POST http://localhost:3001/api/events/42/slots \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "extraSlots": 2
  }'

Example Response

{
  "ok": true,
  "message": "Reserved slots updated."
}

Field Notes

Field Description
state One of upcoming, current, or past. List responses only include upcoming and current.
capacityState One of unlimited, under_capacity, full_capacity, or over_capacity.
participantsJoined Number of users joined as participants. This does not include extra reserved slots.
reservedSlots Total extra slots reserved by all participants.
attendeeCount Total attendance count: participants plus all extra reserved slots.
currentUserReservedSlots Extra slots reserved by the logged-in user on the event details endpoint.

Expo Client Flow

  1. Call POST /api/auth/login and store token.
  2. Call GET /api/events with the bearer token to show joinable events.
  3. Call GET /api/events/{id} before showing a details screen.
  4. Use POST /join, POST /leave, and POST /slots for event actions.
  5. Refresh event details after each mutation to show updated capacity and joined state.

Never ship test credentials in the mobile app. Use secure environment configuration for the API base URL.
